This chapter presents EgoLog, a mobile sensing framework for daily logging with head-mounted wearables. EgoLog focuses on both the activity and scenario aspects of daily life, which represent short-term actions and long-term contexts, respectively. EgoLog differentiates between user and environment to achieve robust recognition in the wild.
The following sections present the introduction, system design, and evaluation of EgoLog.
